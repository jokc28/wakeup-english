# 옥모닝 데이터 삭제 안내

옥모닝은 사용자의 개인정보를 최소한으로 수집하며, 모든 학습/알람 데이터는 기본적으로 단말 내부에만 저장됩니다.

## 삭제되는 데이터 종류

| 데이터 | 저장 위치 | 삭제 방법 |
|---|---|---|
| 알람 설정 | 단말 내부 (Drift SQLite) | 앱 삭제 시 즉시 자동 삭제 |
| 학습 진도 (XP, 레벨, 마스터한 표현) | 단말 내부 | 앱 삭제 시 즉시 자동 삭제 |
| 무료 체험 시작 시각 | 단말 내부 (SharedPreferences) | 앱 삭제 시 즉시 자동 삭제 |
| 구독 기록 (RevenueCat 익명 ID) | RevenueCat 서버 | 아래 절차에 따라 요청 |

## 1. 단말 내부 데이터 삭제

옥모닝 앱을 삭제하면 단말에 저장된 모든 알람/학습/체험 데이터가 즉시 사라집니다.

- **Android**: 설정 → 앱 → 옥모닝 → 제거
- **iOS**: 홈 화면에서 옥모닝 아이콘 길게 누르기 → 앱 삭제

추가 절차나 별도 요청 없이 처리됩니다.

## 2. 구독 데이터 삭제 (RevenueCat 익명 ID)

구독 사용 이력이 있는 경우에만 해당합니다. 구독 한 적이 없으면 RevenueCat에 등록된 데이터 자체가 없습니다.

### 요청 방법

다음 이메일로 요청해 주세요:

> **secalabs1@gmail.com**

**제목**: `옥모닝 데이터 삭제 요청`

**본문에 포함할 정보**:
- 구독 시 사용한 Google Play 또는 App Store 계정 이메일 (대조용)
- 원하시는 처리: ☑ 전체 삭제 / ☑ 익명화만 (선택)

영업일 기준 **3일 이내**에 다음을 처리해 드립니다:
1. RevenueCat 대시보드에서 해당 User ID 조회
2. RevenueCat의 [User Deletion API](https://www.revenuecat.com/docs/delete-customer)로 데이터 완전 삭제
3. 처리 완료 회신

### 자동 보존 기간

운영자가 명시적으로 삭제하지 않더라도 RevenueCat은 자체 정책에 따라 비활성 사용자 데이터를 일정 기간 후 자동 삭제합니다 (RevenueCat 개인정보처리방침 참조).

## 3. 구독 자체 해지 (별개)

데이터 삭제와 별도로 자동 갱신을 멈추고 싶으신 경우:

- **Android**: Google Play → 메뉴 → 구독 → 옥모닝 → 해지
- **iOS**: 설정 → Apple ID → 구독 → 옥모닝 → 해지

해지는 즉시 반영되지만 결제 데이터 자체는 위 2번 절차로 별도 삭제 요청해 주셔야 합니다.
